Type bullets + sub-bullets to build the web. Drag nodes. Click a node to collapse/expand its children. Shift-click to pin/unpin. Duplicate labels merge into a single shared node.

BULLETS
Use -, *, or •.
Tab indents the current line/selection.
Enter continues a bullet.
Press Enter again on an empty bullet to step back out one level (no blank line).
Shift+Enter makes a plain newline.
Gestures
• Drag = move node
• Shift+Click = pin/unpin node
• Click node = collapse/expand subtree
• Scroll / trackpad = zoom
• Drag background = pan
Note: link lines stay stable across edits/resets.
