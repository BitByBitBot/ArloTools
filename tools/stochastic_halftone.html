Pipeline
Gamma is applied to luminance before density mapping (lower = more contrast in darks).
FM Stipple Controls
Constant dot size, density varies by tone. Attempt count × image area controls total points. Spacing avoids clumps.
Stochastic Dither Controls
Pixel-level stochastic halftone. Blue-ish noise reduces low-frequency artifacts.
Reaction–Diffusion Halftone
Gray–Scott simulation guided by image tone. Works at a reduced grid for speed; upscales cleanly. Try presets, then nudge F/K for more stripes (lower F/K) or more spots (higher F/lower K).
Output
SVG contains vector circles (stipple mode). PNG is the exact raster preview.
Tip: For a classic FM screen look, try radius 1.2–1.6, spacing 3–6, attempts ≈ 0.8–1.5, and gamma 0.8–1.2.
