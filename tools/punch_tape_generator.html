How it works

  • Each character maps to 7 data bits (ASCII). If 8 channels are chosen, a parity bit is added.
  • Parity bit ensures total 1s per column are even/odd (when enabled).
  • Reserved sprocket lane prevents feed/data collisions; you can move its position and size.
  • Bit order only changes left/right visual ordering of significance.
